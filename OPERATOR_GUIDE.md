# PAC Ticket Staff: quick guide

1. Open the customer web-app link with `?page=admin`.
2. Enter the private admin token supplied by the system owner.
3. Start with **payments waiting for review**. Check the amount, show, and slip.
4. Choose **Confirm payment** for a valid transfer. Tickets stay reserved.
5. Choose **Reject payment** for an invalid slip. Add a helpful optional note; tickets become available again.
6. If you click a decision twice, the system refuses/reports the already reviewed booking and cannot release tickets twice.

Do not share the token, make the payment-slip Drive folder public, or manually edit booking statuses in the spreadsheet.
